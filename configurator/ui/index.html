Connect to the board

  1. Plug the board's USB into this PC without the WiFi adapter and power it up. It boots into debug mode and ADB appears after ~15 s.
  2. Pick the device above and press Connect.

In debug mode the video link is off, so settings are saved and used on the next FPV boot. Live changes need the SSH link over wfb (not built yet).

Board scripts

Image (ISP)

Changes apply live while FPV runs. iq keeps the value from the IQ file. For FPV, the settings that matter most are, in order: the longest exposure (motion blur), temporal noise reduction (ghosting on fast moves), the gain cap (noise at night), and the AE delay (bright to dark). Change one setting at a time and compare.

IQ file (sensor tuning)

The stock files are never changed. Edits go to a copy in /userdata/iq; every replaced version is kept, and a custom file that does not start falls back to stock automatically.
