Preview

The link stream itself: same encoder, resolution, bitrate, GOP and OSD as what goes over the air. Only radio effects (packet loss, MCS) are missing. Live settings (Image tab, bitrate) show at once; settings that restart the video reconnect by themselves.

Connect to the board

  1. Plug the board's USB into this PC without the WiFi adapter and power it up. It boots into debug mode and ADB appears after ~15 s.
  2. Pick the device above and press Connect.

In debug mode the video link is off, so settings are saved and used on the next FPV boot. Or use the board's WiFi hotspot (hold BOOT 2 s) and pick WiFi hotspot above.

Connect over USB

  1. Plug the board's USB into this PC (or an Android phone with an OTG cable) without the WiFi adapter and power it up. It boots into debug mode after ~15 s.
  2. Press Connect and pick the board (Rockchip / rkfpv) in the browser's list.

Only one program can use the board at a time: if adb runs on this PC, run adb kill-server first. Everything works over USB, including installing the board scripts, IQ files, recordings and the live picture. Disconnect lets go of the board again.

First time on Linux or Windows

Linux: a normal user may not open USB devices. Run once, then replug the board:

echo 'SUBSYSTEM=="usb", ATTR{idVendor}=="2207", TAG+="uaccess"' | sudo tee /etc/udev/rules.d/70-rkfpv.rules
sudo udevadm control --reload-rules

Windows: the board's ADB interface needs the WinUSB driver (the Google USB driver, or Zadig → WinUSB). If Connect says access is denied, install it and replug.

Connect over the board's WiFi

  1. Power the air unit with its WiFi card. After boot, hold the BOOT button for about 2 s: the card becomes a WiFi hotspot named rkfpv-XXXX.
  2. Join that WiFi on this device. If the phone says it has no internet, choose stay connected (or turn mobile data off).
  3. Come back here and press Connect. Chrome asks to allow access to devices on the local network: allow it.

Settings, the live picture and recordings all work over the hotspot. Hold BOOT again to go back to FPV. Install this page (browser menu → Install app / Add to Home screen) while you have internet; it then opens without internet on the hotspot.

Boot mode

What the board does at power-up. Auto: debug mode (ADB) when a PC is on USB, otherwise FPV.

WiFi hotspot

Hold the board's BOOT button for about 2 s (after boot has finished) and the WiFi card becomes an access point: join it, then change settings, watch the live picture and download recordings without USB. Hold BOOT again to go back to FPV.

Board scripts

Copy fpv, S99fpv and wfb.sh from this repo to the board (until the next image is flashed).

Image (ISP)

Changes apply live while the video runs. iq keeps the value from the IQ file. For FPV, the settings that matter most are, in order: the longest exposure (motion blur), temporal noise reduction (ghosting on fast moves), the gain cap (noise at night), and the AE delay (bright to dark). Change one setting at a time and compare.

IQ file (sensor tuning)

The stock files are never changed. Edits go to a copy in /userdata/iq; every replaced version is kept, and a custom file that does not start falls back to stock automatically.
