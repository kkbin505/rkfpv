几十块的开发板，
做一套开源数字图传

rkfpv 跑在 Luckfox Pico Mini（RV1103）上：摄像头画面用 H.265 硬件编码，通过 wfb-ng 发出去， 和 OpenIPC 地面站兼容。电脑上有配置工具，不用焊串口就能改设置。

打开网页版设置器 GitHub 编译和烧录步骤

怎么工作

天空端 SC3336 摄像头→ISP→H.265 编码→RTP→wfb_tx
5 GHz 无线 · FEC
地面端 wfb_rx→UDP 5600→解码→显示

地面端照常接收 UDP 5600 上的 H.265 RTP，现有的 OpenIPC 地面站不用改。 飞控的 MAVLink 遥测走同一条无线链路。

功能

H.265 图传可用

720p 30 帧，CBR 码率，wfb-ng FEC。实机已经跑通整条链路。

配置工具可用

仿 Betaflight Configurator 的电脑界面，通过 USB（ADB）改设置、看状态、备份和恢复。Windows 和 Linux 都能用。

MAVLink 遥测可用

飞控串口的数据打包后走 wfb-ng 上下行，地面站可以直接连接。

多种网卡可用

支持 RTL8812AU、RTL8812CU、RTL8812EU，三张卡的发射功率用同一种方式设置。

画质调节实验

曝光、降噪、色彩等参数可以实时调；IQ 文件上传前校验，出问题自动退回出厂版本。

TF 卡录像实验

录制到 TF 卡的独立分区，分段 MP4，断电后文件也能播放。默认关闭，内存优化完成后再开放。

WiFi 热点模式实验

拨一下开关，网卡变成热点：手机或电脑连上就能下载录像、改设置，不用拔 USB。

OSD实验

编码器直接把飞行模式、电池、链路质量、飞行时间叠加到画面上。

需要的硬件

主板Luckfox Pico Mini（RV1103，64 MB 内存）
摄像头SC3336（3MP MIPI）
天空端网卡RTL8812AU / RTL8812CU（8822CU）/ RTL8812EU，接在板子唯一的 USB 口上
存储TF 卡，4 GB 以上
供电独立的 5 V 电源，至少 1 A：网卡发射时电流很大
地面端任意 wfb-ng 地面站（OpenIPC 地面站、带 RTL8812AU 的 Linux 电脑等）

上手步骤

  1. 按 编译步骤 用 Luckfox SDK 编出 sd_update.img，烧到 TF 卡。
  2. 板子直接插电脑（先不接网卡），进入调试模式，打开 configurator/fpvconf.py 改设置。
  3. 拔掉电脑，接上网卡和独立电源，板子自动进入 FPV 模式，开始发图传。
  4. 地面端用相同的密钥和信道启动 wfb-ng，就能看到画面。
